This project involves building a multi-agent AI-powered banking customer support system that automates customer interactions using Generative AI. 
The system classifies incoming customer messages as positive feedback, negative feedback, or support queries, then routes them to specialized agents for appropriate handling.
It generates personalized responses, creates and tracks support tickets for complaints, retrieves ticket statuses from a database, and provides timely customer updates. 
The solution also includes evaluation, logging, and a Streamlit-based dashboard to monitor agent performance, routing accuracy, and customer support workflows.

For database, mysql server is used running in a docker compose container. Details of the same can be found inside the database folder.
